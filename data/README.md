# Dataset

`forestfires.csv` is the UCI **Forest Fires** dataset (id 162): 517 records from Montesinho Natural Park, Portugal.
Cortez, P. & Morais, A. (2007). *A data mining approach to predict forest fires using meteorological data.* Licensed CC BY 4.0.

This copy was taken from a public GitHub mirror because UCI was not reachable where the project was built. It was checked
against UCI's published description: 517 rows, 13 columns, no missing values, 247 records with area = 0, and identical
value ranges for every column (FFMC 18.7-96.2, DMC 1.1-291.3, DC 7.9-860.6, ISI 0-56.1, temp 2.2-33.3, RH 15-100,
wind 0.4-9.4, rain 0-6.4, area max 1090.84). To use the original instead, download it from
https://archive.ics.uci.edu/dataset/162/forest+fires and replace this file.
